# 🎬 أداة المونتاج الآلي — استخراج أفضل المقاطع الجاهزة للنشر

أداة سطر أوامر (Python + ffmpeg) تحلّل الفيديوهات، وتكتشف أفضل اللحظات، وتُخرجها مقاطع جاهزة
للنشر على **TikTok / Instagram Reels / YouTube Shorts** أو بأي نسبة أبعاد تريدها.

## 1) التهيئة (مرة واحدة)

```bash
bash tools/highlights/setup.sh
```

ينشئ بيئة افتراضية في `~/.venv-video` ويثبّت: `numpy`, `Pillow`, `opencv-python-headless`,
`imageio-ffmpeg` (يجلب نسخة ffmpeg ثابتة جاهزة).

## 2) الاستخدام

ضع مقاطعك الخام في `media/in/` ثم:

```bash
~/.venv-video/bin/python tools/highlights/highlights.py \
    --input media/in --out media/out --top 5 --len 20 --aspect 9:16
```

المخرجات في `media/out/`:

| الملف | الوصف |
|-------|-------|
| `<اسم>_clipNN_*.mp4` | المقاطع المختارة (مرمّزة H.264 + AAC، صوت مطبّع، تلاشٍ) |
| `thumbs/contact_sheet.jpg` | لوحة اتصال (Contact Sheet) لكل المختارات مع أزمنتها ودرجاتها |
| `thumbs/thumb_NN.jpg` | صورة مصغّرة لأفضل لحظة في كل مقطع |
| `reel_all_clips.mp4` | فيديو ملخّص يجمع المختارات (عند استخدام `--reel`) |
| `report.md` | تقرير عربي: الأزمنة، الدرجات، وأسباب اختيار كل مقطع |
| `report.json` | نفس البيانات بصيغة JSON لأتمتة لاحقة |

## 3) كيف تختار الأداة "أفضل" مقاطع؟

تحلّل كل فيديو على عدّة محاور ثم تجمعها في درجة مركّبة:

| المحور | المعنى | الوزن الافتراضي |
|--------|--------|-----------------|
| `motion` | مقدار الحركة (نشاط الكادر) — أعلى 10% من العيّنات داخل النافذة | 1.0 |
| `audio` | مستوى الصوت + نسبة وجود كلام/نشاط صوتي | 0.9 |
| `face` | وجود وجوه وحجمها في الكادر (كشف Haar) | 0.7 |
| `sharp` | حدّة الصورة (تباين لابلاس) — يعاقب الاهتزاز والضبابية | 0.6 |
| `scene` | إيقاع تغيّر المشاهد (الأفضل ~0.12 تغيّر/ثانية) | 0.4 |
| `silence` | **عقوبة** الصمت | 1.2 |
| `blur` | **عقوبة** الضبابية/الاهتزاز | 0.8 |
| `dark` | **عقوبة** الإضاءة السيئة (مظلم جداً أو محروق) | 1.0 |
| `static` | **عقوبة** اللقطة الثابتة المملة (بدون وجه) | 0.8 |

ثم:

1. تُقيَّم نوافذ زمنية منزلقة بطول `--len` وخطوة `--step`.
2. تُمنع المقاطع المتداخلة أو المتقاربة (`--min-gap`) والمتشابهة بصرياً (بصمة إطارات، تشابه > 0.94).
3. تُضبط حدود كل مقطع بحثاً عن أفضل قصّة، ثم **تُحاذى على أقرب تغيّر مشهد أو صمت** (±1.5 ثانية)
   حتى لا يُقطع الكلام في منتصف الجملة.

## 4) أهم الخيارات

| الخيار | الافتراضي | الوصف |
|--------|-----------|-------|
| `--input`, `-i` | `media/in` | ملف فيديو أو مجلد |
| `--out`, `-o` | `media/out` | مجلد الإخراج |
| `--top` | `5` | عدد المقاطع المختارة لكل فيديو |
| `--len` / `--min-len` / `--max-len` | `20` / `10` / `35` | طول المقطع المستهدف بالثواني |
| `--aspect` | `keep` | `keep` أو `9:16` أو `1:1` أو `16:9` |
| `--height` | `1920` | ارتفاع الإخراج (مع 9:16 يعني 1080×1920) |
| `--fill` | `crop` | عند اختلاف النسبة: `crop` (قصّ مع تمركز على الوجه) أو `blur` (خلفية ضبابية) أو `pad` |
| `--fps` | `30` | حد أقصى للإطارات (0 = بدون تحديد) |
| `--fade` | `0.3` | تلاشي أسود في البداية والنهاية |
| `--crf` / `--preset` | `20` / `veryfast` | جودة وسرعة الترميز |
| `--weights` | — | أوزان مخصّصة: `--weights motion=1.4,face=1.2,silence=2.0` |
| `--subs` | — | دمج ملف ترجمة `.srt` |
| `--reel` | — | دمج المختارات في فيديو واحد |
| `--dry-run` | — | تحليل واختيار فقط بدون تصدير (سريع) |
| `--no-faces` / `--no-scenes` | — | تعطيل كشف الوجوه/المشاهد لتسريع التحليل |
| `--no-normalize` | — | عدم تطبيع مستوى الصوت (loudnorm) |

## 5) أمثلة جاهزة

```bash
# أفضل 6 لحظات عمودية بطول 15 ثانية لكل فيديو في المجلد
python tools/highlights/highlights.py -i media/in -o media/out --top 6 --len 15 --aspect 9:16 --height 1920

# مقطع واحد طويل (60 ثانية) بنسبة 1:1 لإنستغرام
python tools/highlights/highlights.py -i raw/vlog.mp4 -o out --top 1 --len 60 --min-len 45 --max-len 75 --aspect 1:1 --height 1080

# استكشاف سريع بدون تصدير لمعرفة الأزمنة المختارة
python tools/highlights/highlights.py -i raw/vlog.mp4 -o out --top 3 --dry-run

# محتوى رياضي/حركي: زد وزن الحركة وقلّل عقوبة الصمت
python tools/highlights/highlights.py -i media/in -o out --weights motion=1.6,silence=0.3 --top 5

# بودكاست/مقابلة: ركّز على الوجوه والكلام
python tools/highlights/highlights.py -i media/in -o out --weights face=1.6,audio=1.4,motion=0.4 --fill blur
```

الفيديو الاصطناعي يحتوي مقاطع مملة/صامتة/مظلمة (يجب أن تتجنبها الأداة) ومقاطع حيوية (يجب أن تختارها).

## 7) ملاحظات

- مجلدا `media/in` و `media/out` مُهملان في Git (لا تُرفع الفيديوهات إلى المستودع).
- التحليل يعمل بمعدل عيّنات منخفض (`--sample-fps 3`)، لذا هو سريع حتى على فيديوهات طويلة؛
  كشف الوجوه يعمل بإطار واحد في الثانية.
- الأداة لا تضيف موسيقى أو شعارات (لا تتوفر أصول مرخّصة داخل المستودع) — أضفها لاحقاً في أي محرر،
  أو اطلب ذلك وسأضيف دعماً لمسار موسيقى/لوجو.

## 8) كيف يصلني الفيديو الطويل؟ (قيود مثبتة بالتجربة)

بيئة العمل التي أعمل فيها **محجوب عنها أغلب مواقع الاستضافة** (Google Drive و Dropbox و Mega و
WeTransfer و YouTube و MediaFire و OneDrive و archive.org… كلها لا تعمل). ما يعمل فعلياً:

| القناة | الحالة |
|--------|--------|
| إرفاق الملف مباشرة في المحادثة | ✅ الأسهل — يعتمد على حد حجم المنصة |
| مستودع GitHub (ملف ≤ 100 ميجابايت) | ✅ تم اختباره (أستطيع التنزيل منه) |
| PyPI / codeload.github.com | ✅ (للأدوات فقط) |
| بقية خدمات الرفع | ❌ محجوبة |

### الطريقة 1 — إرفاق مباشر (جرّبها أولاً)
اسحب الملف إلى نافذة المحادثة. إن رُفض بسبب الحجم، استخدم الطريقة 2 أو 3.

### الطريقة 2 — رفع على GitHub ثم أنزله أنا
1. أنشئ مستودعاً فارغاً (أو استخدم أي مستودع لديك).
2. ارفع ملفات الفيديو عبر **Add file ← Upload files** (الحد 100 ميجابايت للملف الواحد؛
   للملف الأكبر جزّئه بـ 7-Zip إلى أجزاء 90 ميجابايت).
3. أعطني رابط المستودع فقط (عام أو خاص — كلاهما يعمل)، وسأستلم الملفات بهذا الأمر
   الذي يعيد تجميع الأجزاء تلقائياً (7z / zip / split):

```bash
bash tools/highlights/fetch_upload.sh https://github.com/USER/REPO main media/in
```

### الطريقة 3 — "بروكسي للتحليل + قصّ من الأصلي" (أفضل جودة، أقل رفع) ⭐
ممتازة لفيديو ساعة ونصف: لا ترفع الأصل أبداً.

1. على جهازك: اسحب الفيديو على `create_proxy.bat` (ويندوز) أو نفّذ `bash create_proxy.sh الفيديو.mp4`
   ← ينتج نسخة مضغوطة 360p (عادة 100–200 ميجابايت لساعة ونصف) تُجزَّأ تلقائياً إن كبرت.
2. ارفعها لي (إرفاق مباشر أو GitHub).
3. **أنا أحلّلها هنا** وأحدّد أفضل اللحظات بدقة، وأُخرج `report.md` + سكربت جاهز:
   `cut_clips.bat` / `cut_clips.sh`.
4. على جهازك: عدّل سطر `ORIGINAL=` داخل `cut_clips.bat` ليشير إلى **الفيديو الأصلي** ثم نفّذه
   بالنقر المزدوج ← تُقصّ نفس اللحظات من الأصل **بجودته الكاملة** دون رفعه.

```bash
# توليد سكربت القصّ يدوياً من أي تقرير سابق
python tools/highlights/make_cut_script.py --report media/out/report.json --aspect 9:16 --height 1080
```

### زمن المعالجة المتوقع لفيديو 90 دقيقة
التحليل (صورة + صوت + وجوه + مشاهد) ≈ **5–10 دقائق**، وتصدير 5 مقاطع ≈ **دقيقة واحدة**.
