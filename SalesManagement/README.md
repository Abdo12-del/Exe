# تاجر برو (Taajer PRO) - نظام إدارة المبيعات ونقاط البيع والمخزون
### برنامج مكتبي محلي أصيل لنظام ويندوز مع قاعدة بيانات MySQL متنقلة ومدمجة (Embedded Portable MySQL)
**التقنيات المستخدمة:** C# 12 | .NET 8 WPF | Entity Framework Core 8 | Portable MySQL / MariaDB | CommunityToolkit MVVM | Inno Setup

---

## 📌 التحليل الشامل للنظام وما تم إنجازه

تم إجراء تحليل معماري وهندسي دقيق وشامل للنظام، واستكمال جميع الأجزاء والوحدات الوظيفية ليصبح البرنامج منتجاً تجارياً عالي الجودة والاعتمادية وجاهزاً للعمل الفوري:

### 1. طباعة الإيصالات والفواتير (Thermal & A4 Invoice Printing)
- **محرك طباعة حرارية (ESC/POS 80mm & 58mm):**
  - دعم أوامر فتح درج الكاشير آلياً عند إتمام البيع (`0x1B 0x70`).
  - دعم أمر القطع التلقائي للورق (`0x1D 0x56`).
  - تنسيق الإيصال الحراري باللغة العربية (Windows-1256 و UTF-8) مع أسماء المنتجات، الكميات، المجموع الصافي، ومبلغ الصرف.
- **طباعة فاتورة بيع رسمية بصيغة A4 (Facture Commerciale):**
  - ترويسة متكاملة ببيانات المحل أو الشركة (NIF, NIS, RC, العنوان والهاتف).
  - جدول تفصيلي للأصناف مع خانات التخفيض، المجاميع، وحالة الدفع (نقدي / كريدي).
- **إعادة طباعة الفواتير السابقة:** إمكانية إعادة طباعة أي وصل سابق مباشرة من شاشة سجل المبيعات.

### 2. إدارة المصاريف والنفقات التشغيلية (Daily Expenses Management)
- تسجيل المصاريف اليومية مصنفة حسب الفئات (إيجار، كهرباء، شحن، وجبات عمال، تنظيف، صيانة...).
- الربط المباشر مع رصيد الصندوق النقدي (خصم فوري للمصاريف النقدية مع قيد في دفتر حركة الخزينة).
- حساب صافي الأرباح الحقيقي اليومي والشهري بدقة تامة:
  $$\text{Net Profit} = \text{Revenue} - \text{Discounts} - \text{COGS} - \text{Returns} - \text{Expenses}$$

### 3. الجرد الفعلي والتسويات المخزنية (Physical Inventory Count)
- خدمة جرد المخازن مع استخراج رصيد المخزون الدفتري ومقارنته بالكميات المحسوبة على أرض الواقع.
- حساب تلقائي لفوارق الجرد (فائض أو عجز).
- إنشاء حركات تسوية مخزنية تلقائية لضبط المخزون الفعلي دون الإخلال بسجل التدقيق.

### 4. قاعدة بيانات MySQL متنقلة ومدمجة (Portable MySQL 8 / MariaDB)
- مجلد مستقل لمحرك MySQL المتنقل داخل `{app}\mysql\` يرفق مع البرنامج.
- منفذ مخصص **3307** لتفادي أي تعارض مع خوادم أخرى.
- تشغيل وإيقاف صامت للمحرك، وتهيئة تلقائية للجداول والبيانات التجريبية في أول تشغيل دون أي تدخل من المستخدم.

### 5. شاشة نقطة البيع السريعة (POS Cashier)
- قارئ باركود سريع يعمل بتناغم تام مع لوحة المفاتيح.
- أزرار اختصار F-Keys كاملة (F2 للباركود، F4 للتعليق، F6 للاسترجاع، F8 للتخفيض، F9 لطريقة الدفع، F12 للإنهاء والطباعة، Esc للإلغاء).
- حظر البيع بالكريدي للزبائن النقدية وفحص سقف الائتمان تلقائياً.

### 6. اللغات ودعم الواجهات
- قواميس لغوية قابلة للتبديل الديناميكي تدعم اللغة العربية (RTL الافتراضية) واللغة الفرنسية.
- نافذة إعدادات لاختبار الاتصال بالسيرفر المحلي أو شبكة المحل (LAN) وأخذ نسخ احتياطية فورية.

## ⌨️ جدول اختصارات لوحة المفاتيح في نقطة البيع (POS)

| المفتاح | الوظيفة |
| :---: | :--- |
| **F2** | تركيز المؤشر في خانة الباركود للبدء بالمسح الضوئي |
| **F4** | تعليق السلة الحالية (Park Cart) لخدمة زبون آخر |
| **F6** | استرجاع السلة المعلقة ومتابعة إتمام البيع |
| **F8** | تطبيق تخفيض إضافي على الفاتورة |
| **F9** | التبديل بين طرق الدفع (نقد / بطاقة / كريدي) |
| **F12** | تأكيد الدفع وفتح درج الكاشير وطباعة الفاتورة والوصل |
| **Esc** | إلغاء ومسح عناصر السلة بالكامل |
| **+** | زيادة كمية المنتج المحدد بمقدار 1 |
| **-** | إنقاص كمية المنتج المحدد بمقدار 1 |
| **Del** | حذف المنتج المحدد من السلة |

## 🚀 دليل بناء وتوزيع البرنامج للعملاء (Packaging & Distribution)

1. **تجهيز حزمة MySQL المتنقلة بضغطة زر:**
   ```cmd
   cd SalesManagement\installer\mysql_portable
   download_mysql.bat
   ```

2. **نشر ملفات البرنامج التنفيذية:**
   ```cmd
   dotnet publish SalesManagement\src\SalesManagement.Desktop\SalesManagement.Desktop.csproj -c Release -r win-x64 --self-contained true
   ```

3. **إنشاء ملف التثبيت المكتبي عبر Inno Setup:**
   ```cmd
   iscc SalesManagement\installer\SalesManagementSetup.iss
   ```

سينتج الملف التنفيذي النهائي:
```
dist\TaajerPRO_Setup_v1.0.0.exe
```
الذي يثبت النظام مع قاعدة البيانات المتنقلة والهوية البصرية وشعار تاجر برو بضغطة زر واحدة!
