# نظام تسيير المبيعات ونقاط البيع الاحترافي (Taseer POS Pro)

نظام متكامل وشامل لإدارة نقاط البيع (POS)، المخزون، ديون الزبائن (الكريدي)، ويومية الصندوق (Z-Report) مع دعم كامل للغة العربية والطباعة الحرارية والفواتير الرسمية.

## 🚀 الميزات المتوفرة في النظام (Taseer POS Pro)

### 1. شاشة الكاشير السريعة (POS Screen)
- بحث فوري بالاسم أو الباركود مع دعم الضغط على **Enter** لإضافة المادة فوراً إلى السلة (يدعم قارئ الباركود USB).
- تصنيفات سريعة للمنتجات (مواد غذائية، مشروبات، ألبان، حلويات، منظفات).
- تحديد الزبون وطريقة الدفع:
  - **نقداً (Cash فوري)** مع حاسبة الباقي للزبون.
  - **على الحساب بالكامل (كريدي / دين)** لتقييد المبلغ بذمة الزبون.
  - **دفع جزئي** (تسبيق جزء نقداً وتقييد الباقي كدين).
- سلة مبيعات ديناميكية مع إمكانية تعديل الكميات وتطبيق التخفيضات.

### 2. سجل الزبائن والديون (الكريدي)
- إدارة كاملة لبيانات الزبائن (الاسم، الهاتف، العنوان، سقف الائتمان).
- متابعة ديون كل زبون بدقة وتنبيه عند تجاوز سقف الائتمان.
- زر **"تسديد دفعة (Règlement)"** لتسجيل دفعات الزبائن النقدية وتحديث الرصيد فوراً.
- استخراج **كشف حساب الزبون (Relevé de compte)** يعرض جميع فواتيره ودفعاته بالتفصيل.

### 3. يومية الصندوق وإغلاق الكاشير (Z-Report)
- حساب النقد الموجود في الدرج بدقة متناهية:
  - `النقد المتوقع = الرصيد الافتتاحي + المبيعات النقدية + تحصيلات ديون الزبائن`.
- طباعة تقرير إغلاق الصندوق الشامل (**Z-Report**) لمطابقة المقبوضات مع الصندوق في نهاية الدوام.

### 4. خيارات طباعة الفواتير
- **إيصال حراري (Thermal 80mm)**: مخصص لطابعات الكاشير الحرارية السريعة مع كود الباركود.
- **فاتورة رسمية كاملة (A4 Invoice)**: للشركات والمؤسسات مع تفاصيل الأسعار، اسم الزبون، ومكان الختم والتوقيع.

### 5. إدارة المخزون وتصدير Excel
- جدول شامل للمنتجات مع حساب هوامش ونسب الأرباح.
- تنبيهات تلقائية للمنتجات التي أوشكت على النفاد.
- تصدير تقرير المبيعات والمخزون مباشرة إلى ملف **Excel (CSV)** مع الحفاظ على الحروف العربية عبر UTF-8 BOM.

### 6. التحليلات المالية والتقارير
- لوحة مؤشرات حية: مبيعات اليوم، صافي الأرباح المحققة، عدد الفواتير، وقيمة المخزون برأس المال وسعر البيع.
- رسوم بيانية تفاعلية (Chart.js) لمبيعات الأسبوع والمنتجات الأكثر طلباً.

## 💻 طرق التشغيل

### الطريقة 1: المعاينة المباشرة (Live Preview)
الخادم يعمل حالياً ومتاح عبر المنفذ `3000`، يمكنك تجربة كافة الشاشات مباشرة من المتصفح.

### الطريقة 2: التشغيل على حاسوب ويندوز
- **لتشغيل الواجهة الرسومية الكاملة**: انقر نقراً مزدوجاً على الملف `run_pos.bat`.
- **لتشغيل النسخة الخفيفة المباشرة**: شغّل الملف `dist/taseer.exe` مباشرة (98KB).

### الطريقة 3: التشغيل عبر سطر الأوامر (Terminal)
```bash
cd web && npm install
npm start
```
ثم افتح: `http://localhost:3000`
