# برنامج تسيير المبيعات (Sales Manager)

برنامج سطح مكتب خفيف لإدارة المبيعات اليومية — واجهة سطر أوامر باللغة العربية،
ملف تنفيذي واحد لنظام **Windows 64-bit** دون الحاجة لتثبيت أي شيء.

## التشغيل

انسخ `dist/taseer.exe` إلى أي مجلد في جهاز ويندوز، ثم شغّله بالنقر المزدوج.

- تُحفظ البيانات تلقائياً في ملف `taseer_data.json` **بجانب الملف التنفيذي**
  (يمكنك فتحه، نسخ نسخه، أو نقله إلى جهاز آخر).
- عند أول تشغيل يُقترح البرنامج تحميل بيانات تجريبية (منتجات جزائرية نموذجية).

## المزايا

| القسم | الوصف |
|---|---|
| **البيع** | سلة مشتريات، حساب الإجمالي تلقائياً، خصم المخزون، وإصدار فاتورة |
| **إدارة المنتجات** | إضافة / عرض / تعديل / حذف — مع سعر الشراء وسعر البيع والكمية |
| **سجل المبيعات** | عرض كل الفواتير بالتاريخ والقيمة، مع تفاصيل أي فاتورة |
| **التقارير** | إجمالي المبيعات والأرباح، مبيعات اليوم، الأكثر مبيعاً، وتنبيه المخزون المنخفض (≤5) |

العملات بالدينار الجزائري (دج).

## هيكل المشروع

```
src/main.c        واجهة المستخدم (القوائم، البيع، التقارير)
src/core.c        منطق الأعمال + حفظ/تحميل JSON (قابل للاختبار على أي نظام)
src/core.h        تعريفات النموذج
src/io.c          طبقة الإدخال/الإخراج (UTF-8 داخلياً، Unicode على ويندوز)
src/test_core.c   اختبارات منطق الأعمال
build.sh          سكربت البناء
dist/taseer.exe   الملف التنفيذي النهائي (Windows x64)
```

## إعادة البناء

يتطلب [Zig](https://ziglang.org) (يمكن تثبيته عبر `pip install ziglang`):

```sh
sh build.sh
```

يبني السكربت: الاختبارات (تُشغَّل على لينكس)، نسخة لينكس للتجربة،
ثم `dist/taseer.exe` عبر الترجمة المتقاطعة:

```sh
zig cc -target x86_64-windows src/main.c src/core.c src/io.c -O2 -s -o dist/taseer.exe
```

النسخة النهائية **ثابتة الربط** (static) — تعمل على أي ويندوز 10/11 64-bit.

## ملاحظات تقنية

- النصوص محفوظة داخلياً بترميز UTF-8، وتُحوَّل إلى UTF-16 عند العرض/القراءة
  عبر `WriteConsoleW`/`ReadConsoleW` — لذا تظهر العربية بشكل صحيح في وحدة
  تحكم ويندوز دون تغيير صفحة الترميز.
- حفظ JSON يتم بعد كل عملية تغيير (إضافة منتج، بيع، تعديل...) وعند الخروج.
- عند فشل أي عملية بيع (مخزون غير كافٍ) لا تُخصم أي كميات جزئياً.
